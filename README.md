# 🥩 Sistema de Gestión de Ventas - Kermesse Anticuchos

Aplicación web móvil desarrollada en Django para la gestión de ventas, control de flujo de caja e inventario en tiempo real durante la Kermesse escolar. Proyecto coordinado para los equipos de cursos.

## 🚀 Características Principales

* **Caja Chica Móvil (`caja.html`):** Interfaz optimizada para teléfonos móviles con cobro dinámico, cálculo automático de vuelto y selección rápida de medio de pago.
* **Módulo de Promociones:** Oferta configurada a $4.000 por unidad o $10.000 por combo de 3 unidades.
* **El Botín Tiqui Tiqui Ti:** Panel transaccional centralizado para seguimiento del pozo común entre los tres cursos.
* **Cierre de Caja Auditorizable (`cierre_caja.html`):** Desglose en tiempo real de pagos en efectivo versus transferencias, junto con métricas por turno (T1, T2, T3).

## 🛠️ Tecnologías Utilizadas

* **Backend:** Python 3.10+, Django
* **Frontend:** HTML5, CSS3, JavaScript (ES6), Bootstrap 5
* **Base de Datos:** SQLite / MySQL
